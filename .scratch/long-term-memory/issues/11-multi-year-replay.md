# 11: 多年经历回放与参数校准报告

**What to build:** 维护者可运行可复现的多年经历回放，对比三种记忆策略，获得包含召回质量、错误、成本和硬约束结果的报告，并据此记录初版参数。

**Blocked by:** 03 — 用实际权限保证外部只读；07 — 时间阈值控制遗忘与线索唤起；08 — 更新当前认识并保留历史依据；10 — 后台积压或规则升级时持续服务

**Status:** ready-for-agent

**Spec:** [长期记忆规格](https://github.com/NoClickView/dsh-superagent-prototype/blob/f5b6a3270f390a8068413fdb61f6d2757c020a30/.scratch/long-term-memory/spec.md)

- [ ] 提供可运行的回放入口，从事件数据经过真实 Runtime 与记忆读取到评测报告，含可控时钟、受控模型及有预算的实际模型评测方式。
- [ ] 比较原文检索、滚动摘要和分层方案，保持相同输入预算及可比较的后台预算，记录所有配置和版本。
- [ ] 情景覆盖旧事实更新、同名实体、稀有重要事件、重复自引、矛盾证据、遗忘后唤起、原文淘汰及长期搁置后恢复。
- [ ] 报告召回、旧事实误用、虚构细节、弃答、输入规模、存储、后台成本和延迟；证据标注独立于被测模型自述。
- [ ] 硬约束验收要求零超限请求、零成功绕过写入、零重复生效，以及中断后只见完整版本；所有相关实现票也必须各自已有验收测试。
- [ ] 给出初版数值尺度、线性系数、时间单位及基准、阈值/水位和预算的选择依据与配置记录；不把对话中的示例常数当作实证结果。
- [ ] 若复杂机制未比基线带来稳定收益，报告实际结果及限制，不修改评价口径制造通过，也不宣称完成真实多年运行。
- [ ] 完成项目类型检查、测试和构建，并复核既有授权、事件路由和执行恢复回归；保持源码与规格范围一致。
