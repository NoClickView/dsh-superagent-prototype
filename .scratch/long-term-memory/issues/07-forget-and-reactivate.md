# 07: 时间阈值控制遗忘与线索唤起

**What to build:** 随着时间推进，记忆按数值阈值减少默认细节并退出常规召回；当强相关线索出现时，旧经历自动以梗概重现，仍服从输入预算。

**Blocked by:** 06 — 后台压缩后按需读取记忆细节

**Status:** ready-for-agent

**Spec:** [长期记忆规格](https://github.com/NoClickView/dsh-superagent-prototype/blob/f5b6a3270f390a8068413fdb61f6d2757c020a30/.scratch/long-term-memory/spec.md)

- [ ] 由程序基于明确时间基准、单位及线性时间项更新有效权重，覆盖详细、梗概、线索及退出常规召回的可观察变化。
- [ ] 使用可配置且版本化的有序阈值，定义等号归属并拒绝非法配置；先前的示例常数不作为已经验证的默认参数。
- [ ] 当前情境达到独立的相关性唤起阈值时，自动返回低权重旧经历；没有足够线索时保持遗忘。
- [ ] 唤起不直接改写长期重要性、事件年龄、真实性或保留期限，情境变化后不无限驻留。
- [ ] 常规阈值只决定候选粒度/资格，唤起也不能绕过范围过滤及输入预算；有效任务状态不因遗忘失效。
- [ ] 若采用不同进入/退出阈值，验证边界抖动行为；不要求后台模型为每次时间推进重新评分。
- [ ] 用可控时钟和跨年事件在 Runtime 内验证日常不再想起、线索自动重现、原文仍在及检索不自我强化。
