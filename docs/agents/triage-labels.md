# Triage Labels

本项目使用本地 Markdown 议题追踪。状态及标签记录在规格或议题文件顶部。

| Canonical role | Local label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | 等待范围与优先级评估 |
| needs-info | needs-info | 缺少必要信息 |
| ready-for-agent | ready-for-agent | 规格可交由代理实施，并按其中的验证要求收敛参数 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 本范围不实施 |

规格的 Status 和 Labels 都使用对应标签。Wayfinder 的 open/claimed/resolved 表达决策生命周期，与上述实施分流状态分开。
